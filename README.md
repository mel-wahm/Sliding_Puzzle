# Sliding Puzzle

A classic 3×3 sliding puzzle built with [Python Arcade](https://api.arcade.academy/).

![Python](https://img.shields.io/badge/Python-3.x-blue) ![Arcade](https://img.shields.io/badge/Arcade-3.x-orange)

## Controls

| Key | Action |
|-----|--------|
| Click | Move a tile |
| ←/→ | Navigate win menu |
| Enter | Select option |
| Q | Quit |

## Run

```
make run
```

### Requirements

- Python 3
- `arcade`
